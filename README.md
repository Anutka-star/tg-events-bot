# tg-events-bot

Ежедневный мониторинг мероприятий Санкт-Петербурга (IT, ИИ, бизнес) с отправкой
новых событий в Telegram-канал.

## Как это работает
- GitHub Actions запускает `parser.py` каждый день в 10:00 по Москве (файл `.github/workflows/daily.yml`).
- Скрипт обходит источники (список в `parser.py` → `SOURCES`), сравнивает с уже
  виденными событиями (`seen.json`) и отправляет только новые в Telegram-канал.
- Первый запуск — «посев»: бот запоминает все текущие события и присылает
  приветствие, без вываливания сотен старых анонсов.
- Если новых событий нет — бот молчит (сообщение не отправляется).

## Источники
ЦРПП «Мой бизнес» СПб, СПб ТПП, Точка кипения СПб, ict2go, all-events, Cloud.ru,
Экспофорум, страницы организаторов на Timepad (могут блокировать запросы — тогда
источник просто пропускается, это видно в логе запуска).

## Настройки (Settings → Secrets and variables → Actions)
- `TG_TOKEN` — токен бота из @BotFather
- `TG_CHAT` — @имя_канала (публичный) или числовой id вида -100... (приватный)

## Кнопочный бот (личка)
`webhook_bot.py` — отдельное Flask-приложение для PythonAnywhere: в личке бота
кнопки-фильтры по темам (IT/ИИ/Бизнес/Английский) и датам (сегодня/неделя/месяц).
Данные берёт из `events.json`, который ежедневно обновляет GitHub Actions.
Настройка — см. INSTRUKCIYA-PYTHONANYWHERE.md.

## Ручной запуск
Вкладка **Actions** → workflow **daily-events** → кнопка **Run workflow**.

## Проверка кода локально (без отправки)
```bash
python parser.py --dry-run
```
