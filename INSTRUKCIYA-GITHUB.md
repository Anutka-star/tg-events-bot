# Инструкция: запуск бота (один раз, ~15 минут)

## Шаг 1. Бот в Telegram (если ещё не создан)
1. В Telegram найдите **@BotFather** (с синей галочкой) → напишите `/newbot`.
2. Придумайте имя (например «События СПб») и логин бота (заканчивается на `bot`).
3. BotFather пришлёт **токен** (длинная строка с двоеточием). Скопируйте его
   в файл `Keys.txt` на рабочем столе в папке Круглов. Никому не пересылайте.

## Шаг 2. Канал
1. Telegram → Новый канал (например «События СПб: IT и бизнес»), тип — на ваш выбор.
2. Добавьте своего бота в **администраторы** канала с правом «Публикация сообщений»
   (Управление каналом → Администраторы → Добавить).
3. Адрес канала:
   - **публичный** канал: адресом будет @имя_канала (укажите его в Keys.txt);
   - **приватный**: перешлите любой пост из канала боту **@getidsbot** — он покажет
     id вида `-100…` (запишите его в Keys.txt).

## Шаг 3. GitHub
1. Зарегистрируйтесь на github.com (если нет аккаунта).
2. Справа вверху «+» → **New repository** → имя `tg-events-bot` → выберите
   **Public** (открытый: секретов в коде нет, а кнопочному боту нужен доступ
   к списку событий events.json) → кнопка **Create repository**.
3. На открывшейся странице нажмите ссылку **uploading an existing file** и
   перетащите в окно ВСЁ содержимое папки `tg-events-bot` с рабочего стола
   (включая скрытую папку `.github` — перетаскивайте всю папку целиком).
   Внизу нажмите **Commit changes**.
   - Если папка `.github` не загрузилась: **Add file → Create new file**, в поле
     имени введите `.github/workflows/daily.yml` и вставьте содержимое этого файла.
4. **Settings → Secrets and variables → Actions → New repository secret**, создайте два:
   - Name: `TG_TOKEN`, Secret: токен бота из шага 1;
   - Name: `TG_CHAT`, Secret: @имя_канала или id `-100…` из шага 2.
5. Вкладка **Actions** → слева **daily-events** → кнопка **Run workflow** → **Run workflow**.

## Проверка
Через 1–2 минуты в канале появится сообщение «🤖 Бот запущен…». Дальше бот сам
проверяет сайты каждый день в 10:00 по Москве и пишет, только если есть новое.

## Признаки проблемы
- В Actions запуск красный → откройте его и пришлите Анне/Claude текст ошибки.
- Приветствие не пришло → проверьте, что бот администратор канала и секреты
  введены без лишних пробелов.
